
# AI Tools Lab

This repository contains practical work completed for the AI Tools Lab machine exercises.

## Project Contents

- `hello.py` - Basic Python program used for the first Git exercise.
- `sorting.py` - Bubble Sort implementation.
- `utils.py` - Utility functions for palindrome checking, vowel counting, and temperature conversion.

## Git Workflow Used

The project demonstrates the basic Git and GitHub workflow:

1. Create a repository on GitHub.
2. Clone the repository locally.
3. Create and modify files.
4. Create feature branches.
5. Commit changes with meaningful messages.
6. Push branches to GitHub.
7. Create Pull Requests for review.
8. Merge changes into the main branch.

## Technologies Used

- Python
- Git
- GitHub
- Visual Studio Code

## Purpose

The purpose of this repository is to practice version control, branching, commits, pushing changes, and collaboration using Git and GitHub.
